# Баланс DeepSeek

Плавающая карточка, всегда видимая в правом нижнем углу: баланс аккаунта DeepSeek.

## Что показывает

- **Баланс** — доступный остаток (пополнения + бонусные кошельки) вашего аккаунта DeepSeek.
- **Пополнить** / **Usage** — ссылки на пополнение и страницу расходов платформы.

## Как работает

- Host-половина читает баланс через встроенный сервис аккаунта DSH (`deepseekAccount.getBalance`) и отдаёт его на `GET /api/deepseek-balance/snapshot`.
- Client-половина рисует плавающую карточку в слоте `shell.overlay` (видна на всех экранах) и обновляется раз в 5 минут.
